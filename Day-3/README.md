FinMate AI – Day 3

Overview

Day 3 focuses on building an AI finance assistant using LangChain and Groq. FinMate is designed to help small retail business owners understand their financial information.

Technologies Used

Python

Google Colab

LangChain

Groq API

Topics Covered

LangChain prompt templates

System prompts

LLM chains

Conversation history

Testing with CSV files

Basic AI agent creation

What I Built

Created a FinMate system prompt.

Connected the prompt with the Groq LLM using LangChain.

Implemented conversation history.

Created test cases to evaluate FinMate's responses.

Built a basic AI agent using create_agent().

Learning Outcome

Learned how to build an AI assistant using LangChain, maintain conversation history, test LLM responses and understand the basics of AI agents.
